# Tạo service mới

1. Đọc GEMINI.md và file docs mà tôi chỉ định (dùng @docs/...).
2. Đề xuất thiết kế dữ liệu (bảng hoặc collection) và danh sách API. DỪNG LẠI chờ tôi duyệt.
3. Sau khi tôi duyệt: tạo project Quarkus, cấu hình DB (đúng thông tin kết nối trong GEMINI.md), migration, entity, repository, service, REST API.
4. Viết test, chạy test và báo kết quả thật (không đoán).
5. Viết README cách chạy. Liệt kê các file đã tạo hoặc sửa.
6. Không làm sang service khác.
